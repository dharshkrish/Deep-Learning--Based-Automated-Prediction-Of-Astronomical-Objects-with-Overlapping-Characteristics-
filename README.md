Deep Learning Based Astronomical Object Prediction

A deep learning-based astronomical object prediction system that analyzes astronomical observations and predicts the corresponding type or class of objects using a trained neural network model.

Features
Loads and preprocesses astronomical observation data.
Performs exploratory data analysis on astronomical features.
Cleans and prepares the dataset for deep learning.
Performs feature selection and normalization.
Trains a deep learning neural network for astronomical object classification.
Predicts the class of astronomical objects from input features.
Evaluates model performance using suitable metrics.
Generates prediction results for unseen astronomical observations.
Visualizes dataset patterns and model performance.
Supports analysis of different astronomical object categories.
Astronomical Object Categories

The system can be used to classify astronomical objects such as:

Stars
Galaxies
Quasars

Additional astronomical object classes can be added depending on the dataset used for training.
